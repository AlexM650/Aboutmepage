ℹ️ Course Learning Architecture Note

This dashboard communicates with the Node.js Express server using standard fetch() API calls:

  • POST /api/contact receives submissions from the Home page contact form.
  • GET /api/contact reads the array stored in data/contactReceived.json.
  • PATCH /api/contact/:id/reply toggles the replied flag and updates repliedAt.
  • DELETE /api/contact/:id allows message deletion when managing your inbox.
